# Incremental development plan

Work one step at a time; do not implement later stages without the user's request.

1. Foundation: Astro, strict TypeScript, shared layout, CSS tokens, basic Spanish page.
2. Homepage first impression: navigation, hero photography, Carolina introduction.
3. Owner-focused sections: services, process, contact, responsive layout.
4. Property grid and detail pages using clearly identified example content.
5. Sanity Studio: listing schema, images, publishing statuses.
6. Connect Sanity content and editable marketing text.
7. SEO and launch: sitemap, canonical URLs, images, checks, Cloudflare Pages and publish hooks.

## Content and design

- Public language: Spanish.
- Name: Carolina Contador Cortes.
- Main objective: owners hire Carolina; property browsing is secondary.
- Reference: warm cream, stone and wood tones; spacious composition; clean type; large photography.
- Provisional generic copy is allowed. Do not invent credentials, sales figures, testimonials, contact details, or service areas.
- Exact location, contact details, domain, portrait, property data, and approved biography remain to be supplied.
